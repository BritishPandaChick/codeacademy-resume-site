# Codecademy Resume Website
A sample of resume website from Codeacademy HTML and CSS section. 

## Tech Stack
- HTML
- CSS

## Instructions
1. Clone or download zip file. 
2. Open index.html file in your browser.
3. You will see a header near the top of the page with the name and email. The center of the page will have two columns. One column will be empty and the other will have all the resume content. At the bottom of the page is the address in the center of the page. There will be a footer at the bottom of the page.
